# 4V Pizza

Tienda de pizzas online hecha con Angular y Bootstrap, siguiendo Atomic Design.

## Cómo arrancarla

    npm install
    ng serve

Se abre en http://localhost:4200/

## Estructura

- `src/app/atoms`: Logo, Precio, Ingrediente y MensajeError
- `src/app/molecules`: Buscador, SelectorCantidad y LineaPedido
- `src/app/organisms`: Navbar, Header, Footer, PizzaCard, ListaPizzas, ResumenPedido y FormularioPedido
- `src/app/pages`: PaginaPizzas y PaginaPedido
- `src/app/models`: PizzaModel y LineaPedidoModel
- `src/app/services`: PedidoService
